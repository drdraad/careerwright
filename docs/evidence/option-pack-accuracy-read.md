What the fix changed, page by page:

- **The defect.** Reed's JSON-LD links every advertiser to Reed's own company-profile page,
  on the page's own host. So every Reed advertiser read as an employer advertising on its
  own site.
- **J01:** `unsupported` became `kept_unknown`. AWD online's page does not say whether it
  is the employer or an agency.
- **J12:** `incorrect` became `missing`. Cathcart Technology "is acting as an Employment
  Agency in relation to this vacancy".
- **J19:** `correct` became `missing`. Excelcare advertises its own care home's vacancy, but
  the old reading got it right only through the same profile link, the reason it got J01
  and J12 wrong.
- **The rule now:** only a link to a site's home page counts as the advertiser's own site.
  Anything else leaves the kind unknown, which fails safe.

## Findings reported, not fixed

These were reproduced on development pages. Each comes from the board's own structured data
or needs the page's text, which the deterministic path does not read. R11 and R12 apply.

- **Agency names read as the employer** (J12 Cathcart Technology, J18 Consula Group LTD,
  J20 Forward Role: `unsupported`; J14 Adecco instead of South Gloucestershire Council:
  `incorrect`).
  - The cause: the boards put the advertiser in `hiringOrganization`.
  - The agency words miss these names, and only J12's text says "acting as an Employment
    Agency".
  - A fix needs the text (model extraction, Task 8) or brand names in the agency words,
    which would be tuning on four pages.
- **J01's pay.** The JSON-LD gives a single £28,000, but the advert says "Up to £28,000 per
  annum". The path reads a fixed amount where the page states only an upper bound.
- **J19's place.** The board lists Greater Manchester, but the advert's text names a care
  home in Bromley. The path asserts the board's place.
- **Work mode.** It is read only from JSON-LD `TELECOMMUTE`, so a hybrid or on-site
  pattern stated in the text is never read (6 missing).
- **C04.** A course that a board lists as a job is read as a vacancy.
- **Course and funding pages.** The Course JSON-LD that Reed's course pages carry (C03, C10)
  is not read. The path has no reader for course or funding pages at all.
