### Important
- **N1. A fetched page whose JSON-LD holds no posting is "none found" (GC6). This defect follows the ruling's own wording.**
  - **Where:** `backend/src/nessa/evidence/pages.py:474-482`, `backend/src/nessa/evidence/acquisition.py:559-569`, `backend/tests/domain/test_pages.py:246`.
  - **What happens:** careers pages commonly carry Organization, WebSite or BreadcrumbList JSON-LD while the advert itself is in the HTML. Such a page gets `extraction = no_job_posting`, counts as `succeeded` (read), and leads `empty_reason` to `none_found_in_sources_checked`. But the HTML was never read, so the true state is unknown, not zero.
  - **Origin:** item 9's wording, which was my own fix text in the first review, allowed exactly this ("a page whose structured data was read and holds no posting may support none found"). Hence ruling-mandated, Important.
  - **Fix:** until round 2 reads the HTML, treat `no_job_posting` from a fetched page as unreadable (count it under `no_posting_readable`). Only an API's own empty answer (Adzuna `count` 0) should support "none found". Then update ACQ-03 and STATE-02.
- **N2. Merging is not serialised per workspace, so two acquisitions running at once can lose a recorded copy.**
  - **Where:** `backend/src/nessa/evidence/acquisition.py:738-746`, `backend/src/nessa/evidence/store.py:562`.
  - **What happens:** `_record_copies` reads its candidates and then merges and deletes jobs with no lock. Suppose run A merges job X away while run B is recording a copy on X. If B's insert commits first, A's `DELETE FROM nessa.jobs` cascades through `job_copies` and `source_claims` and silently removes B's copy and claims; B's attempt still says `succeeded`. If A deletes first, B's insert fails its foreign key: the step ends `unknown_failure:IntegrityError` (not retried), and B's attempt stays `pending` for good.
  - **Fix:** take `pg_advisory_xact_lock` on the workspace at the start of the recording transaction, or lock the candidate jobs `FOR UPDATE` in a fixed order. Add an integration case with two overlapping runs.
